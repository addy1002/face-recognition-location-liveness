# face-recognition-location-liveness
A smart and secure AI-powered attendance system that uses Face Recognition, Liveness Detection, Geolocation Verification, Flask, and Firebase to automate and authenticate attendance in real time.
Features:
1.Real-time face recognition
2.Liveness detection (anti-spoofing)
3.GPS-based attendance verification
4.Firebase Realtime Database integration
5.Firebase Storage support
6.Flask backend for handling logic
7.Web-based interface using HTML, CSS, and JavaScript
8.Attendance logs and export functionality
9.Preprocessing and encoding using face_recognition
10.Fast, secure, and scalable

Backend:
Python
Flask
OpenCV
face_recognition
Mediapipe (optional for liveness)
NumPy

Frontend:
HTML
CSS
JavaScript
Browser Geolocation API

Database:
Firebase Realtime Database
Firebase Storage
